# ADR: Optional LLM explanation

- Status: Proposed
- Date: 2026-11-26

## Context

README の Status は、現状を静的解析のみとし、静的解析と並ぶ任意の LLM による説明を計画している。Acknowledgements は、概念のきっかけが curl-bash-explain であることを述べたうえで、shxray はいまスクリプトを実行せず、外部 API も呼ばないローカルの静的解析だけを行うと書いている。同じ節は、将来この決定的な静的解析と任意の LLM による説明を組み合わせ、構造化された事実と自然言語の文脈を併せて出せるようにする、と続けている。

README の Report と ADR 0003 は、解析関数が `AnalysisReport` を返すだけであり、ターミナル表示も将来の HTML もそのレポートから描く、としている。解析器は表示を知らない。

## Decision

事実の源は静的解析の `AnalysisReport` とする。任意の LLM による説明は、後からそのレポートの上に重ねる。説明を足す場合、入力は構造化された `AnalysisReport` であり、スクリプト原文からの推測にはしない。スクリプトは実行しない。説明は静的な事実を上書きしない。説明はオプトインであり、説明が無くてもツールはオフラインで、いまと同じ静的解析として使える。

## Decision Details

- 現行の要約、フロー、`--json` の `AnalysisReport` は、LLM が無い状態で完結する結果である。
- 説明の有無にかかわらず、入力スクリプトは実行しない。コマンド置換も実行しない（README の Scope、ADR 0001、ADR 0002）。
- 説明は、レポートが既に持つ構造化された事実と併記する自然言語の文脈である。`platforms` や `privileges` などの静的な記録を書き換えない。
- オプトインを指定しない実行は、外部 API もローカルのモデルも呼ばない。README が今書いているとおり、外部 API は呼ばない。
- この ADR は方針の記録である。実装はまだ無いので、状態は `Proposed` のままとする。

次は未決であり、この ADR では決めない。

- 説明をどこに出すか。ターミナルの追加節、`--json` の追加フィールド、別コマンド、将来の HTML のいずれか。
- `AnalysisReport` に説明文を持たせるか。ADR 0003 は、フィールドの追加は version 1 のままにし、削除や意味の変更で version を上げる。説明をレポートに入れること自体は、まだ選んでいない。
- モデルをどこで動かすか。ローカルのモデルか、外部 API か。ADR 0001 は実行時権限を `--allow-read` と `--allow-env` だけとし、ネットワーク権限は与えない。外部 API を使う場合に、その権限をどのエントリへ付けるかは未決である。オプトイン無しの既定の実行へネットワーク権限を足すとは、ここでは決めない。
- オプトインの指定方法（フラグ、環境変数、設定ファイル）は未決である。
- 説明の言語、モデル名、プロンプトは未決である。

## Alternatives Considered

- スクリプト原文を LLM に渡して説明させる案。README は静的解析の事実と自然言語の説明を併記すると書いており、表示の入力は `AnalysisReport` である（ADR 0003）。原文からの推測は採らない。
- 説明を既定で有効にする案。Status は任意の説明であり、現行は静的解析だけで完結する。既定にすると、説明が無い環境ではツールを使えなくなる。
- 説明の結果で静的な事実を訂正する案。Acknowledgements は事実と説明を併せて出すと書いており、事実の置き換えではない。

## Consequences

- オフラインの静的解析は、説明機能が後から足されても、その機能に依存しない。
- 説明が事実と異なる文を出しても、`AnalysisReport` 側の事実は残る。
- モデル、プロンプト、表示位置、権限の付け方は、実装時に別途決める。

## Verification / Guardrails

1. 説明を実装するまでは、現行のテストがローカルのフィクスチャだけで通り、ネットワーク取得とスクリプト実行をしない。
2. 説明を足したあとも、オプトインを指定しない実行は、LLM を呼ぶ前と同じ静的レポートを出す。
3. 説明の有無にかかわらず、入力スクリプトは実行しない。
